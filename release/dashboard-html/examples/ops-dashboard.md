# Operations Dashboard Example

## 用户输入

```txt
帮我做一个运营 dashboard，顶部是 4 个 KPI 卡片，中间左侧放趋势图，右侧放异常提醒，底部放任务表格。要求输出完整独立 HTML，整体保持轻量，并适配桌面端、平板和手机端。
```

## 期望输出

- 输出应为完整独立 HTML 页面。
- 页面应沿用统一外层容器和卡片式结构，而不是每块都重新定义样式。
- 顶部应有 2-4 列 KPI 区，中部应形成主内容 + 辅助说明的双栏结构。
- 底部任务表格应放在独立卡片中，不和 KPI 或提醒区混排。
- 平板宽度下中部双栏仍应保持可读；手机端下双栏应堆叠，KPI 应降列。
- 整体应保持生成式 UI dashboard 的信息扫描效率，而不是转成营销页或重视觉展示页。
